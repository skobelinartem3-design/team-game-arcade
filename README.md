# Fallout: Battle for the High Score

Пошаговая консольная игра на C++ по мотивам Fallout. В ней есть рейд с риском, покупка аптечки за крышки и случайное событие D20.

## Сборка и запуск

~~~sh
g++ -std=c++17 -Wall -Wextra -Wpedantic game.cpp -o game
./game
~~~

Для повторяемого игрового примера можно передать числовой seed, например ./game 12345. Если seed не передан, используется текущее время.

## Механики

- **Рейд** — шанс 50% получить 200–500 очков и 20–50 крышек; иначе герой теряет 30–50 HP.
- **Убежище** — аптечка стоит 20 крышек, восстанавливает 25–45 HP; здоровье ограничено 100.
- **Случайная встреча** — бросок D20: критическое проклятие на 1, джекпот на 20 и множитель x3 на 18–19.
